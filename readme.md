# 12주차 AI 협업 프로그래밍 실습

## 1. 실습 개요

이번 실습에서는 Python의 pandas 라이브러리를 사용하여 CSV 파일을 불러오고, 데이터 정제 및 분석을 진행하였다.

또한 AI가 작성한 코드를 직접 실행하고 결과를 확인했으며, pytest를 이용하여 데이터 정제와 분석 결과가 올바른지 검증하였다.

## 2. 개발 환경

- Python: 3.13.15
- pandas: CSV 데이터 처리 및 분석
- pytest: 코드 및 결과 검증
- Visual Studio Code: 코드 작성 및 실행
- 운영체제: Windows

## 3. 파일 구성

| 파일명 | 설명 |
|---|---|
| analysis.py | CSV 데이터 정제 및 분석 코드 |
| test_analysis.py | pytest를 이용한 테스트 코드 |
| scores_2026.csv | 기본 실습 데이터 |
| scores_2026_cp949.csv | CP949 인코딩 실습 데이터 |
| mini.csv | 손계산 및 코드 결과 비교용 데이터 |
| prompts.txt | AI에게 전달한 프롬프트 기록 |

## 4. 주요 실습 내용

### ① CSV 데이터 확인

pandas의 `read_csv()`를 사용하여 CSV 파일을 불러왔다.

`info()`, `isnull().sum()`, `duplicated().sum()`, `value_counts()` 등을 사용하여 데이터의 구조와 결측값, 중복 행, 과목별 데이터 개수를 확인하였다.

### ② 데이터 정제

원본 데이터 114행을 기준으로 다음 작업을 수행하였다.

| 정제 단계 | 남은 행 수 | 제거된 행 수 |
|---|---:|---:|
| 원본 데이터 | 114 | - |
| 점수 결측 행 제거 | 108 | 6 |
| 중복 행 제거 | 104 | 4 |
| 점수 범위 초과 행 제거 | 100 | 4 |

정제 후 반 종류는 2개, 과목 종류는 3개로 확인하였다.

### ③ 데이터 필터링 및 그룹화

- 수학 과목 데이터 추출
- 1반이면서 점수가 90점 이상인 데이터 추출
- 반별 평균 점수 계산
- 과목과 반별 평균 점수 비교

### ④ 통계 및 검증

`groupby()`와 `agg()`를 사용하여 반별 인원수, 평균, 중앙값, 최댓값을 계산하였다.

또한 반별 점수 합계와 전체 점수 합계, 반별 인원수와 전체 행 수를 비교하여 결과를 검증하였다.

### ⑤ 손계산 결과와 코드 비교

`mini.csv`를 사용하여 데이터를 직접 정제하고 반별 평균을 계산한 다음 코드 실행 결과와 비교하였다.

정제된 데이터는 총 7행이며, 반별 평균은 다음과 같이 확인하였다.

- 1반: 80.0점
- 2반: 70.0점

### ⑥ pytest 테스트

`test_analysis.py`를 작성하여 데이터 정제 결과와 통계 계산이 올바른지 확인하였다.

최종 테스트 결과는 다음과 같다.

- 전체 데이터 행 수 확인
- 반 종류 확인
- 점수 범위 확인
- 반별 점수 합계 검증
- 손계산 평균과 코드 결과 비교

최종 실행 결과: **6 passed**

### ⑦ CP949 인코딩 실습

CP949로 저장된 CSV 파일을 기본 UTF-8 방식으로 읽었을 때 `UnicodeDecodeError`가 발생하는 것을 확인하였다.

이후 다음과 같이 인코딩을 지정하여 정상적으로 파일을 불러왔다.

```python
df = pd.read_csv("scores_2026_cp949.csv", encoding="cp949")
```

실행 결과 데이터 크기는 `(114, 5)`로 확인하였다.

## 5. 실행 방법

프로젝트 폴더에서 터미널을 열고 다음 명령어를 실행한다.

**1) 분석 코드 실행**

```powershell
python analysis.py
```

**2) 테스트 실행**

```powershell
python -m pytest -q
```

**3) 필요한 라이브러리 설치**

```powershell
pip install pandas pytest
```

## 6. 실습 결과 및 느낀 점

이번 실습을 통해 CSV 파일을 불러오는 것부터 데이터 정제, 통계 분석, 결과 검증까지의 과정을 경험하였다.
특히 데이터에 결측값이나 중복 행, 점수 범위를 벗어난 값이 포함되어 있으면 분석 결과가 달라질 수 있다는 점을 확인하였다.

AI가 작성한 코드를 그대로 사용하는 것보다 직접 실행하고 오류가 발생한 원인을 찾아 수정하는 과정이 중요하다는 것을 알게 되었다.
